## 摘要
CARLA中的闭环驾驶基准通过将路线完成度乘以违规惩罚得到的驾驶分数来对智能体排名。该分数无法区分在障碍物前停下的智能体与强行越过障碍物的智能体。例如，在由两辆停放车辆封闭的走廊中，一个发生接触仍驶过去的智能体在受阻宽度上的平均得分为52.2，而停下的智能体平均得分在37.8到40.6之间。我们提出失效边界剖面，这是一种评估方法：每个场景族变化一个可测量因素，例如走廊宽度或对向交通中的时间间隙，并依据测量将每个变体认证为智能体应继续通行或应停止的变体。沿该轴，我们为每个智能体估计两条曲线——承诺度（尝试通行的概率）和胜任度（无接触通过的概率）——并定位各自穿过1/2的位置，同时给出考虑仿真器运行间方差的区间。认证标签还给出一个汇总指标——决策准确率，它奖励在可通行变体上无接触通过以及在受阻变体上停止。我们在七个CARLA场景族上评估七个驾驶智能体。基于规则的专家达到0.74的决策准确率，而得分最高的学习型智能体TFv6达到0.60。驾驶分数相近的智能体以不同方式失效；即使在受阻走廊中可靠停下的智能体，也仍然很少等待对向交通中出现间隙。我们还将该方法原样应用于Isaac Sim中的仓库机器人。我们测试的导航策略仅在三个场景族中的一个中会在受阻间隙处停下，而其两个微调版本虽然能无接触通过更多间隙，却完全不再停下。

## Abstract
Closed-loop driving benchmarks in CARLA rank agents by a driving score that multiplies route completion by an infraction penalty. This score does not distinguish an agent that stops in front of an obstacle from one that pushes past it. In a corridor closed by two parked cars, for example, one agent that drives through with contact averages 52.2 on the blocked widths, while the agents that stop average between 37.8 and 40.6. We propose failure-boundary profiles, an evaluation in which each scenario family varies one measured factor, such as corridor width or the time gap in oncoming traffic, and each variant is certified from measurement as one where the agent should proceed or one where it should stop. Along this axis we estimate two curves per agent, commitment (the probability of attempting the passage) and competence (the probability of passing without contact), and locate where each crosses one half, with intervals that account for the simulator's run-to-run variance. The certified labels also give a summary metric, decision accuracy, which credits clean passes on passable variants and stops on blocked ones. We evaluate seven driving agents on seven CARLA families. The rule-based expert reaches a decision accuracy of 0.74 and TFv6, the highest-scoring learned agent, 0.60. Agents with similar driving scores fail in different ways, and agents that reliably stop at a blocked corridor still rarely wait for a gap in oncoming traffic. We also apply the method, unchanged, to a warehouse robot in Isaac Sim. The navigation policy we test stops at blocked gaps in only one of three families, and two fine-tuned versions of it pass more gaps cleanly but no longer stop at all.

## 二、方法论

### 2.1 核心思想

- 每个**场景族（scenario family）F** 只改变**一个可测因子** x（走廊最小自由宽度、侵入深度、对向车流穿越时间间隙、物体身份、机器人间隙宽度等），其余场景要素保持不变；每个变体 x₁<…<x_V 都依据**测量结果**被认证为“应通过（passable/usable）”或“应停止（blocked/wait）”。
- 沿该轴为每个智能体估计两条概率曲线，并定位其与 **0.5** 的交点（失效边界），配以**考虑仿真器运行间随机性的区间**。

### 2.2 关键指标与公式（文字说明）

- **承诺度（Commitment）**：`P_go(x) = Pr[G=1 | x, a, F]`，G 表示该次运行是否尝试通行（进入通道/进入对向车道）。
- **胜任度（Competence）**：`P_clean(x) = Pr[C=1 | x, a, F]`，C 表示该次运行为 **CLEAN PASS**（无接触通过）。两曲线**分别估计**：迟到承诺（超时后才通过）计入 go 但不计入 competence，故不保证 `P_clean ≤ P_go`。
- **失效边界**：曲线与 p=1/2 的交点。对方向 σ∈{+1,−1}（越大越易/越难），用 logistic 拟合 `P̂(x) = [1+exp(−βσ(x−x*))]⁻¹` 求交点。分四种情形处理：
  1. 至少一个变体出现混合结果 → 受约束拟合，取拟合中点；
  2. 失败/通过变体完全分离 → 无拟合，取相邻两变体中点，报为**分离区间（bracket）** `[x_fail, x_pass]`；
  3. 拟合不收敛（如仅一个混合变体）→ 用 bracket 替代；
  4. 全程未跨越 1/2 → **不报边界**，标题注明 “flat / not located in range / below tested range”。
- **不确定性**：把每次运行视为独立伯努利抽样，同一变体内**合并多个交通种子**（固定种子并不能复现运行），边界用 **bootstrap 重采样**（变体内重采样运行）给出 95% 区间；bracket 自带区间；flat 曲线用 Wilson 区间。
- **承诺–胜任缺口**：`Δ_a(x) = P_go(x) − P_clean(x)`，即“仍敢尝试但已不能干净完成”的区间，图中以橙色标出，其位置与宽度因智能体而异。
- **决策准确率（Decision Accuracy）**：`DA = ½[ Pr(G=1,C=1 | passable) + Pr(G=0 | blocked) ]`，即两类上的**平衡准确率**。可通行侧必须是**干净通过**（撞过去不算对，因为“完不成的机动就不该尝试”），受阻侧奖励停止；迟到承诺计为可通行侧的漏判；异常运行（在受阻变体上无接触通过）剔除。**全停 = 0.5，全走 ≤ 0.5**。汇总时对**含“停止侧”的族等权平均**（仅 4 族：Charger gauntlet + 两个对向流族；纯可通行族不进入），区间为按族、按侧重采样的 bootstrap（10,000 次）。条件型（conditional）流窗口单独报告，不进入两侧。
