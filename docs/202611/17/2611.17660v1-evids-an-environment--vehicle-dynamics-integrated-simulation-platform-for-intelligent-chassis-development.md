## 摘要
智能底盘的发展日益需要将环境与感知信息同高保真车辆动力学相集成，以支持环境感知型智能底盘控制。然而，现有的自动驾驶仿真器与专业车辆动力学工具通常面向不同目的开发，难以将环境信息、车辆动力学与底盘算法进行集成。本文提出EViDS，一个面向智能底盘开发的环境—车辆动力学一体化仿真平台。EViDS将基于CARLA的环境与传感器仿真同基于CarSim的高保真车辆动力学相集成。基于参考位姿的状态对齐与多速率交互可保持空间和时间一致性，而基于射线投射的轮胎—路面交互则将环境信息传递至车辆动力学模型。场景配置、同步数据采集与算法接口进一步支持智能底盘开发。该平台通过环境—动力学交互测试、车辆动力学一致性对比以及智能底盘应用进行评价。结果表明，EViDS能够保持车辆动力学特性、可靠传递环境信息，并支持在线闭环智能底盘控制，为环境感知型智能底盘的开发与验证提供了统一的仿真基础。

## Abstract
The development of intelligent chassis increasingly requires the integration of environmental and perception information with high-fidelity vehicle dynamics to support environment-aware intelligent chassis control. However, existing autonomous-driving simulators and professional vehicle-dynamics tools are generally developed for different purposes, making it difficult to integrate environmental information, vehicle dynamics, and chassis algorithms. This paper proposes EViDS, an Environment-Vehicle Dynamics Integrated Simulation Platform for Intelligent Chassis Development. EViDS integrates CARLA-based environment and sensor simulation with CarSim-based high-fidelity vehicle dynamics. Reference-pose-based state alignment and multi-rate interaction maintain spatial and temporal consistency, while ray-casting-based tire-road interaction transfers environmental information to the vehicle-dynamics model. Scenario configuration, synchronized data acquisition, and algorithm interfaces further support intelligent chassis development. The platform is evaluated through environment-dynamics interaction tests with vehicle-dynamics consistency comparisons, together with intelligent chassis applications. Results show that EViDS preserves vehicle-dynamics characteristics, reliably transfers environmental information, and supports online closed-loop intelligent chassis control, providing a unified simulation basis for environment-aware intelligent chassis development and validation.

## 2. 方法论

### 2.1 总体架构（三层集成）

- **CarSim**：通过 S-function 接口接入 MATLAB/Simulink，承担高保真车辆动力学计算，输出车辆位姿与四个轮胎接地点位置。
- **CARLA**：通过 Python API 访问，承担环境、场景与多源传感器（RGB、语义分割、LiDAR、深度）仿真。
- **MATLAB/Simulink**：作为中央集成层，负责状态同步、轮胎—路面交互、仿真管理与算法接入；算法可在 Simulink 内实现，也可用 Python 外部开发后经 Python 接口接入。
- **数据分层**：跨域交换变量（车辆位姿、轮胎接地点、道路高度与摩擦）与域内私有变量（额外动力学状态、CARLA 传感器数据）分离管理，避免不必要的耦合。

### 2.2 三项关键跨域交互机制

- **基于参考位姿的状态对齐**
  - 以 CARLA 地图生成的初始位姿作为公共参考，同时传给 CarSim 做初始化，从而把两套坐标系统一到同一原点与航向上。
  - 平面位置映射：`p_C_xy(t) = p0 + T(ψ0)·(p_S_xy(t) − p0)`，其中 `T(ψ0) = R(ψ0)·M·R(−ψ0)`，`M = diag(1, −1)` 用于吸收 ISO 与 UE 的轴向差异，`R` 建立相对初始航向的旋转关系。
  - 姿态映射：`[ψC, θC, φC] = [wrap180(2ψ0 − ψS), −θS, φSE]`，即偏航与俯仰需镜像翻转，横滚采用 CarSim 提供的欧拉横滚角。
  - 对齐后的位姿用于 CARLA 车辆同步，变换后的接地点用于轮胎—路面查询。

- **多速率数据交互**
  - 动力学需以高步长 `T_dyn` 求解，而场景渲染、车辆同步、传感器更新可用较长周期 `T_env`。
  - 以 Simulink 的 `T_dyn` 为主时钟；累计时间达到 `T_env` 时才触发 CARLA 世界更新。
  - 但轮胎—路面信息直接参与动力学计算，因此在**每个动力学步**都用变换后的接地点做射线查询，并以 `T_dyn` 速率把摩擦系数 μi 与路面高度 zi 回送 CarSim，避免两次环境更新之间漏掉局部路面变化。

- **基于射线投射的轮胎—路面交互**
  - 在每个接地点水平位置 `(x_C_i, y_C_i)` 处向下发射射线，以对齐位姿的车辆高度 zC 为参考，起点取 `zC + 3 m`、终点取 `zC − 30 m`。
  - 按语义标签处理命中结果：跳过自车（Label 10）与无关物体；仅影响摩擦的物体记录 μi 后继续下探以获取真实路面高度；同时影响摩擦与几何的物体直接取其 μ 与碰撞高度作为 μi、zi；最终到达底层路面时以路面属性为准。
  - 由此实现"路面属性直接来自虚拟环境"，而非仅依赖 CarSim 中预定义的道路输入。

### 2.3 面向底盘开发的功能模块

- **场景配置与测试设置**：图形界面支持地图可视化、场景/机动选择、参考路径生成与数据导出；建立独立场景库，含 **11 类场景**（住宅、商业、工业、公园、城市混合、密集路口、高速/多车道、环岛、坡道/桥梁、郊区乡村、封闭测试场）与 **9 种机动定义**（两类双移线、单移线、定半径圆周、车道跟随、曲线跟随、坡道跟随、环岛跟随、传统双移线），组合出 **94 种地图—场景—机动—布点方案**；路径在 CarSim 局部坐标与 CARLA 世界坐标间双向映射。
- **复杂路面与环境物体配置**：支持从 CARLA 蓝图库直接部署锥桶、障碍物等通用物体；并引入**自定义路面资产**，可指定材质外观、语义标签与对应道路物理属性（局部摩擦变化、高程扰动），使感知层面与动力学输入源自同一虚拟场景。

## 3. 实验设计

- **实验环境**：CARLA 0.9.11 + CarSim 2019.1 + MATLAB/Simulink 2021b。
- **验证一：环境—动力学交互验证（两组典型工况）**

  - **局部高程扰动场景**：路面几何突变，随车辆通过被逐轮检测。
  - **Benchmark / 参照**：以**独立 CarSim 仿真并给定等效道路输入**作为参考基准，比较轨迹、横摆角、俯仰角、横滚角响应。
  - 指标：RMSE。
- **验证二：智能底盘应用（感知—估计—控制闭环）**
  - 三类估计分支：① 仅底盘的可学习卡尔曼滤波（物理模型 + 数据驱动残差修正）；② 基于 RAFT-Stereo、LoFTR、RANSAC-PnP 的双目视觉里程计基线（不直接从图像回归侧偏角）；③ 质量感知的视觉—底盘多源卡尔曼融合估计器。
  - 估计状态送入带侧偏稳定性约束的运动控制器，控制指令回注 CarSim 车辆模型，形成完整闭环。
  - **对比方法**：chassis-only、vision-only、fusion 三者互比，并按参考侧偏角幅值（低/中/高三档）与纵向车速（低/中/高三档）分组统计 MAE。

## 6. 主要结论与发现

- **动力学一致性得以保持**：异质摩擦场景下轨迹 RMSE = 0.137 m、横摆角 RMSE = 0.046 deg；高程场景下俯仰角 RMSE = 0.012 deg、横滚角 RMSE = 0.036 deg，与独立 CarSim 参考高度吻合，说明 CARLA 侧获取的摩擦与高程信息被正确传入动力学模型并产生预期响应。
- **时空对应关系成立**：四个轮胎因空间位置差异在不同时刻进出局部区域，摩擦系数与高程按轮胎接地点逐一变化，验证了环境属性与轮胎运动之间的时空对应。
- **环境信息可可靠传递**：路面属性与几何信息能同时从环境域传入动力学域，且不破坏原有动力学特性。
- **支持在线闭环**：融合估计器在最高车速区间 MAE = 0.00438 rad（chassis-only 0.00971 rad、vision-only 0.00442 rad），在最大侧偏幅值区间 MAE 最低为 0.01208 rad；但多个其他工况下 chassis-only 或 vision-only 反而最优，说明**没有单一信息源在所有工况下占优**，多源互补具有条件依赖性。
- **工作流可行性**：验证了"平台内初步开发 → 实车数据精化 → 回注平台在线闭环"的三阶段流程可在统一接口下完成。

## 7. 优点

- **问题定位准确**：清晰指出现有工具"环境强/动力学弱"与"动力学强/环境弱"的结构性割裂，切中智能底盘开发的真实工程痛点。
- **坐标对齐处理严谨**：用统一的参考位姿 + 镜像矩阵 M + 相对航向旋转构造映射，显式处理 ISO 与 UE 约定的轴向与旋向差异，公式简洁且可复现。
- **多速率机制设计合理**：区分"环境更新慢、路面反馈必须快"的物理需求，在保持渲染效率的同时不牺牲动力学输入的时间分辨率，是工程上务实的设计。
- **射线投射 + 语义过滤**：将路面属性获取从"预定义输入"转为"从虚拟场景直接查询"，并按语义标签分类处理（跳过自车、仅摩擦物体继续下探、摩擦+几何物体直接采用），使感知与动力学共享同一场景来源。
- **自定义路面资产**：解决了通用资产在几何、材质、语义、道路属性关联上的灵活性不足，支持受控的局部摩擦与高程实验。
- **场景库工程化**：11 类场景 × 9 种机动 × 94 种组合，并提供 GUI 与坐标双向映射，具备实际可用性；平台承诺开源。
- **验证思路清晰**：以独立 CarSim 等效输入作为一致性基准，是平台类工作中较为合理的评价方式；应用部分覆盖"开发—精化—闭环"完整链路。
